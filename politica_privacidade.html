Política de Privacidade

Última atualização: 09 de Novembro de 2026

1. Coleta de Informações

O aplicativo "Mente em Foco" é uma ferramenta local. Não coletamos, armazenamos ou compartilhamos dados pessoais dos usuários em servidores externos. Todo o processamento de vídeo e texto ocorre na máquina do próprio usuário.

2. Uso da API do TikTok

Utilizamos a API oficial do TikTok exclusivamente para enviar vídeos gerados pelo usuário para a sua própria caixa de entrada (Rascunhos). Não acessamos, lemos ou modificamos outras informações da sua conta no TikTok.

3. Tokens de Acesso

Os tokens de autenticação (Access Token e Refresh Token) são armazenados localmente no computador do usuário e nunca são transmitidos para terceiros.

4. Contato

Para dúvidas sobre esta política, entre em contato pelo e-mail: renansuporte@gmail.com
